\begin{frame}{The question}
\begin{itemize}
\item RL with verifiable rewards: sample answers, a checker grades them, update $g=\sum_i A_i\nabla\log\pi(y_i)$.
\item Many papers modify the advantage $A_i$ (PSR: $A=r$; NSR: $A=r-1$; constant baselines; pass@$k$ weights; entropy terms) and report higher \textbf{pass@$k$}.
\item They compare methods \textbf{at equal training steps}, which confounds pass@$k$ with progress in pass@1.
\item We compare \textbf{pass@16 at matched pass@1}: linear interpolation along Dr.\ GRPO's trajectory and temperature envelope, bootstrap over problems.
\end{itemize}
\end{frame}

\begin{frame}{Theory: per-problem direction, rule-dependent noise}
For any correctness-only advantage rule, per problem $x$ with $p_x=\Pr_\pi(r=1\mid x)$:
\[\E g_x=c(p_x)\,\nabla p_x,\qquad \E\|g_x\|^2=F_1D_1(p_x)+F_0D_0(p_x)+\|\nabla p_x\|^2X(p_x)\]
\begin{itemize}
\item A rule changes only the per-problem coefficient and the second moment; $F_0/F_1$: 2.14--2.54 (OLMo), 2.7--3.4 at initialization, 1.4--1.6 later (Qwen).
\item Cross-problem reweighting can rotate the aggregate update (shared parameters), so a common curve is an empirical question.
\item At matched pass@1, $P_k=N^{-1}\sum_x[1-(1-p_x)^k]$ depends only on the dispersion of $\{p_x\}$.
\end{itemize}
\end{frame}

\begin{frame}{A model of the frontier}
\begin{block}{Per-question log-odds learning from base counts}
\[\theta_x(0)=\log\tfrac{c_x+a}{n-c_x+b},\qquad \dot\theta_x=p_x(1-p_x)+\tau\,\overline{p(1-p)}\]
\end{block}
\begin{itemize}
\item Inputs: the base model's per-question success counts; each checkpoint's pass@1 (sets progress $t$).
\item $\tau=-0.20$ fitted once on Dr.\ GRPO, then \textbf{frozen} (pre-registered).
\item Predicts $P_k$ for $k>1$, stratum-level $P_{16}$ and per-problem count likelihoods.
\item State-dependent log-odds dynamics: under a uniform log-odds shift the $c=0$ stratum would reach 70--80 pass@16; observed 24.
\end{itemize}
\end{frame}

\begin{frame}{Reading}
\begin{itemize}
\item Within these settings, the matched-pass@1 frontier of policies trained from the base model is reproduced by the \textbf{base count distribution} and per-problem dynamics with weak transfer.
\item In the model the frontier depends on two quantities: the \textbf{initial count distribution} and the \textbf{transfer coefficient} $\tau$; advantage reweighting changes neither.
\item \textbf{Warm start}: $c=0$ stratum residual $-11.92$ pp; refitted $\tau=-0.65$ to $-0.70$ in all seeds: the supervised stage changes the subsequent dynamics.
\item Against the model's base-initialized trajectory: warm start $+3.3$ to $+3.6$ pp, groups of 32 $+3.9$ pp at step 150, Dr.\ GRPO $-1.2$ to $+0.5$; T3 measures the extrapolation error.
\end{itemize}
\end{frame}
